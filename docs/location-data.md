# Location data provider constraints

The in-app circle picker uses Leaflet with the official OpenStreetMap raster tile endpoint, `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, and visible © OpenStreetMap contributors attribution. The tile policy says the public tiles are donation/sponsorship funded and best-effort with no service-level guarantee; clients must identify the app, honor cache headers (or at least seven days where applicable), avoid bulk downloads/offline prefetch, and provide attribution. The map picker is therefore an online-only, active-view map and must permit switching tile provider without app-source changes where practical. [1]

Do not call public `nominatim.openstreetmap.org` as an embedded generic geocoding/search service. Its usage policy limits use to at most one request per second, requires app identification and attribution, and specifically says public Nominatim must not be built into/automatically generated by no-code/low-code/vibe-coding platforms as a generic location search service. Use only Android's system `Geocoder` for destination resolution, if it is available; if it returns no result, fail closed and do not auto-accept a request inside unverified exclusion circles. Explain that Android's system geocoder may use the device provider/network and that destination text may leave the device for that provider. [2]

Leaflet supports circles specified by a center and a radius in meters. OSM's tile URL and required attribution are described in its official quick start. [3]

[2]: https://operations.osmfoundation.org/policies/nominatim/ "Nominatim Usage Policy"
[3]: https://leafletjs.com/examples/quick-start/ "Leaflet Quick Start Guide"
